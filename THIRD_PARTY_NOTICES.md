the [vector tile policy](https://operations.osmfoundation.org/policies/vector/).
Its optional traditional mode uses the OpenStreetMap standard raster tile service over HTTPS.

The MIT license on this repository does not relicense OpenStreetMap data or imagery.

The public tile service is operated by the OpenStreetMap Foundation. Its
[tile usage policy](https://operations.osmfoundation.org/policies/tiles/) and
[privacy policy](https://osmfoundation.org/wiki/Privacy_Policy) apply.
Do not use this project to bulk-download, prefetch regions or redistribute tile archives.
The synthetic grid in automated tests is generated by this project; tests never use the live tile service.

City Drift also bundles simplified OpenStreetMap **vector map data** for Paris,
Boston and Tokyo, obtained via the Overpass API. The editable derivative database,
source timestamps, processing details, attribution and ODbL 1.0 license are in
[Assets/StarterMaps](Assets/StarterMaps/README.md) and accompany the installed map
saver. This dataset is licensed under ODbL 1.0, not MIT. These are separately
rendered roads, street names, water/park geometry and named places; no standard raster tile archive is distributed.
Overpass is used only by the explicit maintainer refresh script, never at runtime.
